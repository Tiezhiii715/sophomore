## 阅读方法

第一遍先说清一句话的意思，再跟着例子走；第二遍合上答案做自测；遇到不理解的推导，回到所标注的原课件页码。公式前提与结论一起记，例如 Euler 必须互素、域只要求非零元素可逆。

所有页码为 PDF 物理页码，从 1 开始，包含动画展开页，不等于课件底部的幻灯片编号。“补充”用于解释省略的推导、举小例子或澄清边界，不代表老师新增了一章。
