# 第 7 节：P、NP 与数论入门，解题和验答案有什么区别

## 1. 先把问题改成回答“是/否”（p15–40）

优化问题问最好能做到多少，判定问题问是否达到某个门槛。背包优化问“容量 $W$ 下最大价值是多少”，判定背包问“能否在容量 $W$ 内达到价值至少 $K$”。

如果会求最优值，再和 $K$ 比较就能做判定。因此判定版本已经难，优化版本至少也得承担这部分难度。

多项式时间指运行时间被输入长度 $n$ 的某个固定次幂 $O(n^k)$ 控制。$k$ 不能随着 $n$ 增长。多项式时间是理论分类，不保证 $n^{20}$ 的算法实际好用。

## 2. P：自己能高效做出判定（p41–45）

P 是可用确定性多项式时间算法解决的判定问题集合。证明在 P：给出一个正确的算法，分析它在输入长度上的运行时间。

证明一个算法很慢，只是在否定这个算法的效率；证明一个问题不在 P，则需要排除所有可能的多项式算法，困难得多。

## 3. NP：给我一个证书，我能高效核验（p46–61）

讲解补充的完整定义：问题属于 NP，意味着对每个 yes 输入，都存在**长度至多为输入长度的多项式**的证书，能被多项式时间验证器接受；对于 no 输入，不应有任何证书骗过验证器。

“证书很短”“检查很快”“错误输入不能混过去”，三点缺一不可。NP 中的 N 是 nondeterministic，不能理解成“non-polynomial”。

课件例子：

- 合数问题：证书是非平凡因子 $a$，检查 $1<a<N$ 且 $a\mid N$。
- 判定背包：证书是选了哪些物品的 0/1 向量，检查总重量不超容量、总价值达到门槛。

$P\subseteq NP$，因为既然自己能多项式时间求出答案，就可以忽略证书直接判定。不能由“在 NP”推出“不在 P”。P 与 NP 是否相等仍属未解决问题，核对来源：[Clay Mathematics Institute](https://www.claymath.org/millennium/p-vs-np/)（2026-10-26 查阅）。

## 4. 归约：把一个问题交给另一个问题处理（p62–80）

$A\le_PB$ 表示存在多项式时间变换 $f$，使

$$x\in A\iff f(x)\in B.$$

原输入和新输入的 yes/no 必须双向一致。只把 yes 映成 yes 不够。

记忆方式：**若有 B 的解题器，就能用来解 A**。先把 A 的输入变换成 B 的输入，再调用 B 的算法。

于是：若 $A\le_PB$ 且 $B\in P$，则 $A\in P$。归约也可传递：$A\le_PB\le_PC$ 得 $A\le_PC$。

反过来，$A$ 容易不能推出 $B$ 容易。把简单题变成复杂题，并不能降低复杂题的难度。

课件通过对数把乘法转换为加法，作为“转换问题”的直观比喻。这不是直接完成一个关于有限二进制编码、精度与开销的多项式归约证明，正式题目仍需检查编码和时间。

## 5. NP 完全：NP 中能承接所有 NP 问题的成员（p81–86）

$L$ 是 NP-complete，当且仅当：

1. $L\in NP$；
2. 每个 $A\in NP$ 都有 $A\le_PL$。

满足第二点称 NP-hard；若还在 NP，就称 NP-complete。NP-hard 作为补充术语帮助区分，不要求它一定是 NP 中的判定问题。

证明新问题 $B$ 是 NP 完全的常用模板：先证明 $B\in NP$，再选一个已知 NP 完全问题 $A$，证明 $A\le_PB$。**要把已知难题归约到新题，方向别反。**

若某个 NP 完全问题进入 P，所有 NP 问题都进入 P，便有 P=NP。课件未给出具体问题完整归约构造，本篇也不把额外构造冒充课堂已讲。

## 6. 整除与带余除法（p91–101）

$a\mid b$ 表示存在整数 $k$ 使 $b=ak$（此处 $a\ne0$）。它是一个判断，不是除法运算符。若 $a\mid b,a\mid c$，则对任意整数 $s,t$ 都有 $a\mid(sb+tc)$。

带余除法：整数 $a$、正整数 $d$ 唯一对应

$$a=dq+r,\qquad0\le r<d.$$

讲解补充：$-17=5(-4)+3$，所以 $-17\operatorname{div}5=-4$，$-17\bmod5=3$。数学上的标准余数必须非负，不能直接照搬某些语言的负数余数行为。

不超过 $N$ 的正整数中，$d$ 的倍数有 $\lfloor N/d\rfloor$ 个；注意不计 0。

## 7. 同余就是“相差整倍数”（p102–114）

$$a\equiv b\pmod m\iff m\mid(a-b).$$

等价地，两者除以 $m$ 的标准余数相同。$15\equiv3\pmod6$，但 $15\bmod6=3$ 是一个具体余数值；$15\equiv9\pmod6$ 也成立，$15\bmod6=9$ 则不成立。

同余可以加、减、乘，也可代入非负整数幂。**不能随便约掉一个因子**：$14\equiv8\pmod6$，除以 2 后 $7\not\equiv4\pmod6$。下一节会给出允许约分的互素条件。

## 8. 自测与答案

1. 证明 $B$ 是 NP 完全，已知 $A$ 是 NP 完全，应证明哪个方向？
2. 已知 $A\le_PB$，若 $B\in P$ 能推出什么？若 $A\in P$ 呢？
3. 求 $-29\bmod7$。
4. 为什么“在 NP”不等于“难以求解”？

<details><summary>展开答案</summary>

1. $A\le_PB$，并且单独证明 $B\in NP$。
2. 前者推出 $A\in P$；后者不能据此判断 $B$ 是否在 P。
3. $-29=7(-5)+6$，余数 6。
4. NP 保证的是 yes 证书可高效核验，且包含 P。
