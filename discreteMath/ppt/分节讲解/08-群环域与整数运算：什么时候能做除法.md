## 1. 模运算里，结果一直绕回有限集合（p7–15）

$\mathbb Z_m=\{0,1,\ldots,m-1\}$。加法、乘法做完后取模，例如模 11：$7+9\equiv5$，$7\cdot9\equiv8$。

加法有单位元 0，每个 $a$ 有加法逆元 $-a\bmod m$；非零 $a$ 的代表可写成 $m-a$。乘法的逆元却不一定存在，例如模 6 时无论乘什么整数，$2x$ 都不能余 1。

## 2. 群、环、域分别多了什么（p16–38）

这些名字在描述：一个集合配合指定运算，能遵守哪些算术规则。只写集合、不写运算，无法判断是不是群。

### 群 group：一个运算能稳定地算和撤销

要求封闭、结合律、单位元、每个元素有逆元。标准写法中单位元左右都适用，逆元左右相乘都得单位元。不要求交换；若还交换，就叫阿贝尔群。

- $(\mathbb Z,+)$ 是阿贝尔群，逆元是相反数。
- $(\mathbb Z,\times)$ 不是群，2 没有整数乘法逆元。
- $(\mathbb Q\setminus\{0\},\times)$ 是阿贝尔群。
- 可逆实矩阵关于矩阵乘法组成群，维数至少 2 时一般不交换。
- 所有整数矩阵中的“非零矩阵”不能等同于“可逆矩阵”。

置换群体现“做操作的顺序重要”。课件 p23–24 的排列约定，是用 $\pi$ 的次序重新排列 $\rho$ 的位置；按该约定 $\pi=\langle3,2,1\rangle,\rho=\langle1,3,2\rangle$，$\pi\circ\rho=\langle2,3,1\rangle$。课件采用的位置重排记法可能与通常将排列看作函数的复合方向不同，考试先确认题目约定。

### 环 ring：加法是阿贝尔群，乘法能结合并分配

乘法封闭、满足结合律，并对加法满足左右分配律。课件对一般环的定义不额外要求乘法交换或单位元，使用时按课程约定。

$\mathbb Z,\mathbb Q,\mathbb R$ 配普通加乘都是交换环；矩阵环一般不是交换环。

### 整环 integral domain：交换、有乘法单位元、没有零因子

非零元素相乘不能变成 0（并取 $1\ne0$）。$\mathbb Z$ 是整环；$\mathbb Z_6$ 不是，因为 $2\cdot3\equiv0\pmod6$。

### 域 field：每个非零元素都可以做乘法逆运算

域是整环，并且每个非零元素有乘法逆元。**必须排除 0**：$0b=0$ 永远不可能等于 1。课件 p37 漏写这个限制，本笔记按标准定义补全。

| 结构 | 环 | 整环 | 域 |
| --- | --- | --- | --- |
| 普通整数 $\mathbb Z$ | 是 | 是 | 否，2 无整数逆元 |
| 有理数 $\mathbb Q$ | 是 | 是 | 是 |
| $\mathbb Z_6$ | 是 | 否，有零因子 | 否 |
| $\mathbb Z_7$ | 是 | 是 | 是 |

对 $m\ge2$，$\mathbb Z_m$ 是域当且仅当 $m$ 为素数。直观原因是素数模下每个非零数都与模互素，从而有逆元。

## 3. 进制与快速模幂（p39–59）

$(a_ka_{k-1}\cdots a_0)_b=\sum_{i=0}^ka_ib^i$，每个数字满足 $0\le a_i<b$。

十进制转 $b$ 进制：反复除以 $b$ 记余数，最后倒序读。例如课件 $12345$ 转八进制，余数依次 1、7、0、0、3，得到 $(30071)_8$。二进制转八进制从右向左三位一组，转十六进制四位一组。

两个 $L$ 位二进制整数，普通加法需 $O(L)$ 位操作，朴素乘法需 $O(L^2)$。一直减去除数的除法可能很慢；课件也给出按二进制递归拆分的除法。

### 为什么快速幂只要处理指数的各个位

计算 $b^e\bmod m$，把指数二进制拆开。例如 $13=8+4+1$，所以只需 $b,b^2,b^4,b^8$ 的模值，再乘对应项。

讲解补充：算 $3^{13}\bmod7$，依次有 $3,2,4,2$，选第 1、4、8 次幂，得 $3\cdot4\cdot2\equiv3\pmod7$。

伪代码：

```text
result = 1 mod m
base = b mod m
while e > 0:
    if e is odd: result = result * base mod m
    base = base * base mod m
    e = floor(e / 2)
return result
```

模乘次数为 $O(\log e)$；采用朴素位运算，模乘本身约花 $O((\log m)^2)$，总位复杂度为 $O((\log m)^2\log e)$，不能把每次大整数乘法都当成一位操作。

## 4. 素因子、GCD 与 LCM（p60–88）

素数是大于 1 且只有 1 和自身正因子的整数。1 不是素数，也不是合数。算术基本定理说明大于 1 的整数有唯一素因子分解，忽略排列顺序。

若合数 $N=ab$，不可能 $a,b$ 同时大于 $\sqrt N$，因此有一个素因子不超过 $\sqrt N$。注意是“不超过”：$N=49$ 的素因子 7 恰好等于平方根。

如果 $a=\prod p_i^{\alpha_i},b=\prod p_i^{\beta_i}$，则 GCD 每个指数取 min，LCM 取 max。例如 $72=2^3 3^2,60=2^2 3\cdot5$，GCD 为 12，LCM 为 360。正整数满足 $\gcd(a,b)\operatorname{lcm}(a,b)=ab$。

更实用的是辗转相除：

```text
287 = 3 * 91 + 14
91  = 6 * 14 + 7
14  = 2 * 7  + 0
```

最后一个非零余数 7 就是 GCD。核心等式 $\gcd(a,b)=\gcd(b,a\bmod b)$，因为两组数拥有相同的公因子。

## 5. Bézout 与同余约分（p89–101）

扩展欧几里得把余数反向代回，得到

$$\gcd(a,b)=sa+tb.$$

课件例子：$1=29\cdot503-51\cdot286$。这能用于求模逆元、证明互素约分。

如果 $ac\equiv bc\pmod m$ 且 $\gcd(c,m)=1$，则 $a\equiv b\pmod m$。互素条件保证 $c$ 在这个模下可逆。

若素数 $p$ 整除一串整数的乘积，它至少整除某一因子，这是素因子分解唯一性的关键。合数不具备相同性质，例如 $6\mid2\cdot3$，却既不整除 2 也不整除 3。

课末 Mersenne 数与素数猜想作为拓展：$p$ 素不保证 $2^p-1$ 素，例如 $2^{11}-1=23\cdot89$。不把课件中的最大已知素数纪录当成需背诵的恒定事实。

## 6. 自测与答案

1. 模 8 的 3 有乘法逆元吗？2 呢？
2. $\mathbb Z_8$ 为什么不是域？
3. 求 $\gcd(252,105)$。
4. “辗转相除次数是对数级”是否说明总位操作数也只需这么多？

1. 3 的逆元为 3，因 $3\cdot3\equiv1$；2 没有逆元。
2. $2\cdot4\equiv0$，有零因子，且非零元 2 不可逆。
3. $252=2\cdot105+42$，$105=2\cdot42+21$，$42=2\cdot21$，得 21。
4. 否，每次除法有自己的位运算成本。
