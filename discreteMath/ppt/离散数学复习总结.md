## 2. 先把话写准确：逻辑

详见第 [1](分节讲解/01-命题逻辑：把一句话变成能计算的真假.md)、[2](分节讲解/02-逻辑等价与量词：所有和存在怎么写.md)、[3](分节讲解/03-嵌套量词与证明：怎样写出站得住的推理.md) 节。来源：lec01 p46–87，lec02 p18–114，lec03 p2–79。

### 2.1 命题与联结词

命题是有确定真假的陈述，未知真假也可以是命题。$x>3$ 若还留有自由变量，尚不是封闭命题。

| 联结词 | 何时真 | 最常见的误读 |
| --- | --- | --- |
| $\neg p$ | $p$ 假 | 否定长句时漏括号 |
| $p\land q$ | 两个都真 | 把“有些 A 是 B”写成箭头 |
| $p\lor q$ | 至少一个真 | 误以为不能都真 |
| $p\oplus q$ | 恰好一个真 | 与 OR 混淆 |
| $p\to q$ | 除前真后假外都真 | 把必要和充分写反 |
| $p\leftrightarrow q$ | 两边真假相同 | 证明时只证一个方向 |

$p\to q$ 表示 $p$ 充分、$q$ 必要，也就是“$p$ only if $q$”。逆否 $\neg q\to\neg p$ 与原式等价；逆命题 $q\to p$、否命题 $\neg p\to\neg q$ 一般不等价。

### 2.2 等价公式速查

$$
\begin{aligned}
p\to q&\equiv\neg p\lor q,\\
\neg(p\to q)&\equiv p\land\neg q,\\
p\leftrightarrow q&\equiv(p\to q)\land(q\to p),\\
p\oplus q&\equiv(p\land\neg q)\lor(\neg p\land q),\\
\neg(p\land q)&\equiv\neg p\lor\neg q,\\
\neg(p\lor q)&\equiv\neg p\land\neg q,\\
p\land(q\lor r)&\equiv(p\land q)\lor(p\land r),\\
p\lor(q\land r)&\equiv(p\lor q)\land(p\lor r),\\
p\lor(p\land q)&\equiv p,\\
p\land(p\lor q)&\equiv p.
\end{aligned}
$$

化简题建议顺序：去箭头和双条件，推入否定，再结合分配律、吸收律。证明恒真可化到 T，也可列真值表检查所有行。$n$ 个独立命题变量有 $2^n$ 种赋值。

### 2.3 量词的翻译与否定

先写论域。若论域是所有人，$S(x)$ 表示学生、$P(x)$ 表示通过考试：

| 中文 | 公式 |
| --- | --- |
| 所有学生通过 | $\forall x(S(x)\to P(x))$ |
| 有学生通过 | $\exists x(S(x)\land P(x))$ |
| 有学生没通过 | $\exists x(S(x)\land\neg P(x))$ |
| 没有学生通过 | $\forall x(S(x)\to\neg P(x))$ |

限定群体的全称常配箭头，存在常配合取。论域已经是学生时，可以省略身份谓词。

$$\neg\forall xP(x)\equiv\exists x\neg P(x),\qquad
\neg\exists xP(x)\equiv\forall x\neg P(x).$$

嵌套时每过一层换一次量词，把否定一直推到谓词。$\forall x\exists y$ 中 $y$ 可随 $x$ 改变；$\exists y\forall x$ 要先找一个对所有 $x$ 都有效的固定 $y$。例如实数上前者可表达“每个数都有更大的数”，后者表达“存在比所有数都大的数”，真假不同。

恰好一个满足 $P$：$\exists y(P(y)\land\forall z(P(z)\to z=y))$。

### 2.4 推理题的写法

先把句子翻译成公式，再列“结论、引用的前提或上一步、规则名称”。常用：

- $p,p\to q\Rightarrow q$，肯定前件。
- $\neg q,p\to q\Rightarrow\neg p$，否定后件。
- $p\to q,q\to r\Rightarrow p\to r$，传递。
- $p\lor q,\neg p\Rightarrow q$，排除一支。

不要从“$p\to q$，$q$”推出 $p$。带量词时，存在证人要用新的名字，不能从一个特殊证人推广到所有对象。

## 3. 把话证明出来：证明工具

来源：lec03 p80–110，lec04 p2–8。

| 目标或信号 | 建议方法 | 作答核心 |
| --- | --- | --- |
| 条件能代入定义 | 直接证明 | 从前提逐步推到结论 |
| 结论的否定更容易表达 | 逆否证明 | 证 $\neg q\to\neg p$ |
| 无理性、不存在、不能列全 | 反证 | 假设目标为假，指出具体矛盾 |
| 奇偶、绝对值、余数区间 | 分类 | 覆盖全部情况，逐类证明 |
| 当且仅当 | 双向证明 | 两个方向都写 |
| 存在一个对象 | 构造 | 给出合法对象并核验 |
| 推翻全称断言 | 反例 | 一个满足条件却不满足结论的对象 |

### 必须能复写的三个证明

**奇数平方仍奇：** $n=2k+1$，则 $n^2=2(2k^2+2k)+1$。

**$\sqrt2$ 无理：** 假设约成最简的 $m/n$，由 $m^2=2n^2$ 推出 $m,n$ 都偶，与互素矛盾。

**素数无穷：** 假设素数只有 $p_1,\ldots,p_k$，构造 $N=p_1\cdots p_k+1$。$N>1$ 有素因子，这个素因子不在表里，矛盾。不要要求 $N$ 自己必为素数。

检查证明时问：变量属于哪里？有没有漏 0 或负数？除掉的量是否为 0？分类是否穷尽？是否把待证结论当作前提？

## 4. 集合与函数：研究对象和对应规则

详见第 [4](分节讲解/04-集合与函数：元素怎么分组和对应.md) 节。来源：lec04 p9–113。

### 4.1 集合必会公式

集合不计顺序与重复。$\varnothing\ne\{\varnothing\}$，大小分别是 0 和 1。$x\in A$ 与 $\{x\}\subseteq A$ 有关联，但“元素”和“子集”的对象层次不同。

$$
\begin{aligned}
A\subseteq B&\iff\forall x(x\in A\to x\in B),\\
A=B&\iff A\subseteq B\land B\subseteq A,\\
A-B&=A\cap\overline B,\\
\overline{A\cap B}&=\overline A\cup\overline B,\\
\overline{A\cup B}&=\overline A\cap\overline B,\\
|\mathcal P(A)|&=2^{|A|}\quad(A\text{ 有限}),\\
|A\times B|&=|A||B|\quad(A,B\text{ 有限}),\\
|A\cup B|&=|A|+|B|-|A\cap B|\quad(A,B\text{ 有限}).
\end{aligned}
$$

集合恒等式可以用任意元素法，把“属于集合”翻译成逻辑，再等价变形。补集必须指定全集 $U$。若用位串表示集合，也要先固定 $U$ 中元素次序。

### 4.2 函数判断题的固定流程

$f:A\to B$ 先检查是否每个输入恰好有一个输出；实际值域 $f(A)$ 可能严格小于陪域 $B$。

| 性质 | 证明方法 | 反驳方法 |
| --- | --- | --- |
| 单射 | 假设 $f(x)=f(y)$ 推 $x=y$ | 找不同 $x,y$ 输出相同 |
| 满射 | 任给 $b\in B$，找到合法 $a\in A$ 使 $f(a)=b$ | 找陪域中一个永远达不到的值 |
| 双射 | 两项都证 | 否定其中任意一项 |

$f:\mathbb Z\to\mathbb Z,f(x)=2x-1$ 单射、不满射；改成 $\mathbb R\to\mathbb R$ 就双射。公式本身不决定所有性质。

双射才有定义在整个陪域上的反函数；$f^{-1}$ 不是倒数。$(f\circ g)(x)=f(g(x))$，先右后左，一般不能交换。有限且等大时单射等价满射，无限时不成立。

### 4.3 取整

$$\lfloor x\rfloor\le x<\lfloor x\rfloor+1,\qquad
\lceil x\rceil-1<x\le\lceil x\rceil.$$

$\lfloor-1.2\rfloor=-2$，$\lceil-1.2\rceil=-1$。取整恒等式常令 $x=k+t$，$0\le t<1$，再按小数部分分类。不要擅自把取整对加法分配。

## 5. 数列、求和与无限集合

详见第 [5](分节讲解/05-数列与可数性：无限集合也能比较大小.md) 节。来源：lec05 p6–72，lec06 p2–15。

### 5.1 公式先检查下标和条件

从 $0$ 到 $n$ 有 $n+1$ 项，从 $m$ 到 $n$ 有 $n-m+1$ 项。

$$
\begin{aligned}
\sum_{k=1}^nk&=\frac{n(n+1)}2,\\
\sum_{k=1}^nk^2&=\frac{n(n+1)(2n+1)}6,\\
\sum_{k=1}^nk^3&=\left(\frac{n(n+1)}2\right)^2,\\
\sum_{k=0}^n(a+kd)&=(n+1)a+d\frac{n(n+1)}2,\\
\sum_{k=0}^nar^k&=a\frac{r^{n+1}-1}{r-1}\quad(r\ne1),\\
\sum_{k=0}^{\infty}r^k&=\frac1{1-r}\quad(|r|<1).
\end{aligned}
$$

等比 $r=1$ 单独算项数乘首项。双重求和先固定外层变量，内层化简后再求外层。递归定义必须配足初始值。

### 5.2 比较基数的两种方法

存在双射则等大；存在单射 $A\to B$ 则 $|A|\le|B|$。两边各有一个单射，可用 Schröder–Bernstein 定理得等大。

本课“可数”含有限与可数无限。整数、有理数、有限字母表上的有限字符串、程序都是可数的；实数、所有无限二进制串、$\mathcal P(\mathbb N)$ 不可数。

有理数用二维对角线列举并跳过重复；字符串按长度再按字典序。不要在一个无限行中永远列下去。

### 5.3 对角线证明模板

假设对象能列为 $s_0,s_1,\ldots$，构造一个新对象，让它在第 $i$ 个位置与第 $i$ 行相反。然后证明它属于目标集合，却不等于列表中的任意一行。

对幂集可直接构造 $D=\{i:i\notin S_i\}$。一般 Cantor 定理用 $T=\{s\in S:s\notin f(s)\}$，推出 $t\in T\iff t\notin T$，得 $|S|<|\mathcal P(S)|$。

程序只有可数多个，函数可有不可数多个，因此存在不可计算函数。这个论证比较数量，不等同于已经找到了某个具体函数的算法。

## 6. 算法复杂度与 P/NP

详见第 [6](分节讲解/06-算法复杂度：运行次数怎样随规模增长.md)、[7](分节讲解/07-P与NP及数论入门：解题和验答案有什么区别.md) 节。来源：lec06 p16–105，lec07 p2–86。

### 6.1 渐近符号

对非负运行时间，O 是最终的常数倍上界，Ω 是下界，Θ 是两边夹住的同阶。常数与输入规模无关。$3n^2+4n$ 在 $n\ge1$ 时夹在 $3n^2$ 和 $7n^2$ 之间，所以是 $\Theta(n^2)$，也是 $O(n^3)$，却不是 $\Theta(n^3)$。

常见增长顺序：$\log n\prec n\prec n\log n\prec n^2\prec n^3\prec2^n\prec n!$。固定幂的对数慢于任意正幂，固定多项式慢于底大于 1 的指数。

| 算法结构 | 固定工作量模型下的时间 |
| --- | --- |
| 累加 $n$ 项 | $\Theta(n)$ |
| Horner 求 $n$ 次多项式 | $\Theta(n)$ 次算术操作 |
| 两个独立 $n$ 次循环嵌套 | $\Theta(n^2)$ |
| 内层 1 到 $i$、外层 1 到 $n$ | $\Theta(n^2)$ |
| 变量反复翻倍直到 $n$ | $\Theta(\log n)$ |
| 插入排序 | 最好 $\Theta(n)$，最坏 $\Theta(n^2)$，等概率排列下平均 $\Theta(n^2)$ |

最好/最坏是在选输入，O/Ω 是上下界，不能简单一一对应。空间复杂度另算，例如只用几个累加变量的循环，辅助空间可以是常数。

### 6.2 先确定输入长度

正整数 $N$ 的二进制长度 $L=\lfloor\log_2N\rfloor+1$。运行 $N$ 次是对数值线性，却是对位数指数级。研究大整数还要计入一次乘除的位成本，不能默认每个超大整数运算都只需一步。

### 6.3 P、NP 与归约

- P：有确定性多项式时间判定算法。
- NP：yes 输入有多项式长度的证书，可以多项式时间验证；no 输入不能有骗过验证器的证书。
- NP-complete：属于 NP，且所有 NP 问题都能多项式归约到它。

$P\subseteq NP$。P 与 NP 是否相等仍未解决，参见 [Clay 官方问题页](https://www.claymath.org/millennium/p-vs-np/)（2026-10-26 核对）。NP 不能读成“非多项式”。

$$A\le_PB\quad\Longleftrightarrow\quad\text{存在多项式变换 }f\text{，使 }x\in A\iff f(x)\in B.$$

如果 B 有高效算法，A 也有；归约具有传递性。要证明新问题 B 难，常从已知难问题 A 出发构造 $A\le_PB$，不要倒过来。一个朴素算法慢，不代表问题本身必然不在 P。

## 7. 数论：一套能反复使用的计算流程

详见第 [7](分节讲解/07-P与NP及数论入门：解题和验答案有什么区别.md)、[8](分节讲解/08-群环域与整数运算：什么时候能做除法.md)、[9](分节讲解/09-同余方程与欧拉定理：大数计算怎样变简单.md) 节。来源：lec07 p91–114，lec08 p39–101，lec09 p2–81。

### 7.1 整除、余数、同余

$a\mid b$ 表示 $b=ak$。若 $a\mid b,a\mid c$，则 $a\mid(sb+tc)$，$s,t$ 为任意整数。

$$a=dq+r,\quad0\le r<d,\qquad a\equiv b\pmod m\iff m\mid(a-b).$$

负数除法也坚持非负余数，例如 $-17=5(-4)+3$。同余可以加减乘及取非负整数幂，但约分须查互素：

$$ac\equiv bc\pmod m,\quad\gcd(c,m)=1\quad\Longrightarrow\quad a\equiv b\pmod m.$$

### 7.2 进制与素数

从十进制转 $b$ 进制，连续除以 $b$，余数倒序读；反向用位权展开。二进制转八进制每三位一组，转十六进制每四位一组。

素数须大于 1。合数存在不超过平方根的素因子，试除时不能漏掉平方根本身。素因子分解中，GCD 的指数取较小值，LCM 取较大值；正整数满足 $ab=\gcd(a,b)\operatorname{lcm}(a,b)$。

### 7.3 GCD、Bézout、模逆元

辗转相除使用 $\gcd(a,b)=\gcd(b,a\bmod b)$，最后一个非零余数为 GCD。反向代回得到 $sa+tb=\gcd(a,b)$。

当 $\gcd(a,m)=1$ 且 $m>1$，$s$ 就是 $a$ 模 $m$ 的逆元。例如

$$1=29\cdot503-51\cdot286,$$

所以 503 模 286 的逆元为 29。逆元在模意义下唯一，代表整数可以有无限多个。

### 7.4 解线性同余的统一步骤

题目 $ax\equiv b\pmod m$：

1. 求 $d=\gcd(a,m)$。
2. 若 $d\nmid b$，无解。
3. 若 $d\mid b$，把 $a,b,m$ 同除以 $d$。
4. 在新模数 $m/d$ 下用逆元求一个解 $x_0$。
5. 若要求模 $m$ 的不同解类，列 $x_0+j(m/d)$，$j=0,\ldots,d-1$。

例如 $6x\equiv8\pmod{14}$，约成 $3x\equiv4\pmod7$，得 $x\equiv6\pmod7$，模 14 下是 6、13。

### 7.5 CRT 拼接余数

模数两两互素时，令 $M=\prod_i m_i$、$M_i=M/m_i$、$y_i=M_i^{-1}\pmod{m_i}$，则

$$x\equiv\sum_i a_iM_iy_i\pmod M.$$

孙子问题 $(2\bmod3,3\bmod5,2\bmod7)$ 的结果是 $23\bmod105$。小规模题可回代，同样要给出最终模数。非互素时不能直接套本版本。

### 7.6 快速幂与指数降阶

快速模幂：指数转二进制，底数不断平方，遇到该位为 1 就乘进结果，每步都取模。它不依赖底数与模数互素。

Fermat：$p$ 素且 $p\nmid a$，则 $a^{p-1}\equiv1\pmod p$。

Euler：$\gcd(a,n)=1$，则 $a^{\varphi(n)}\equiv1\pmod n$。

$$\varphi(p^r)=p^r-p^{r-1},\qquad
\varphi(pq)=(p-1)(q-1)\quad(p,q\text{ 为不同素数}).$$

满足互素条件后才能按相应周期缩减指数。例如 $7^{222}\bmod11=7^2\bmod11=5$。如果不互素，先改用快速幂或分别分析素因子，不能硬套 Euler。

## 8. 群、环、域：哪些运算有保证

来源：lec08 p7–38。

| 名称 | 要求 | 代表例子 |
| --- | --- | --- |
| 群 | 一个运算封闭、结合、有单位元、每元有逆元 | $(\mathbb Z,+)$ |
| 阿贝尔群 | 群再加交换律 | $(\mathbb Q\setminus\{0\},\times)$ |
| 环 | 加法阿贝尔群，乘法封闭结合，左右分配 | $\mathbb Z$、矩阵环 |
| 整环 | 交换环，有 $1\ne0$，无零因子 | $\mathbb Z$ |
| 域 | 整环的每个非零元都有乘法逆元 | $\mathbb Q,\mathbb R,\mathbb Z_p$（$p$ 素） |

一般群不要求交换。一般环按本课定义不额外要求乘法单位元。判断反例时优先找失败条件：整数乘法中 2 无逆元，模 6 中 $2\cdot3=0$ 是零因子，矩阵乘法一般不交换。

模 $m\ge2$ 下，元素 $a$ 可逆当且仅当 $\gcd(a,m)=1$；因此 $\mathbb Z_m$ 是域当且仅当 $m$ 素。域不允许除以 0。

原根的幂遍历乘法群的所有元素，模 7 时 3 是原根，2 不是。课件关于原根存在的分类、一般同余解的数量有带星标记，应保留以供进阶复习，具体深度以课程要求为准。

## 9. 密码学：知道流程，更要说清为什么

详见第 [10](分节讲解/10-密码学：RSA、ElGamal与密钥交换为什么有效.md) 节。来源：lec10 p26–113。

| 方法 | 公开内容 | 秘密内容 | 核心操作 |
| --- | --- | --- | --- |
| RSA 加密 | $(e,n)$ | $d$，以及 $p,q,\varphi(n)$ | $C=M^e\bmod n$，$M=C^d\bmod n$ |
| ElGamal 加密 | $(p,g,y)$，$y=g^x$ | 私钥 $x$，每次加密的随机数 $k$ | $(a,b)=(g^k,My^k)\bmod p$ |
| DH 密钥交换 | $p,g,g^u,g^v$ | $u,v$ 与共同秘密 | 两方都算出 $g^{uv}\bmod p$ |

### 9.1 RSA 的计算与证明

不同素数 $p,q$，$n=pq$，$\varphi(n)=(p-1)(q-1)$，选 $e$ 与 $\varphi(n)$ 互素，求 $ed\equiv1\pmod{\varphi(n)}$。

课件例：$p=5,q=11,e=7,d=23$，消息 28 加密成 52，再解密回 28。

对所有消息证明正确性，分别模 $p,q$：若素数整除消息，两边同为 0；否则用 Fermat，因为 $p-1,q-1$ 都整除 $ed-1$。最后用 CRT 合并。仅用模 $n$ 的 Euler 定理会漏掉与 $n$ 不互素的消息。

改用 $\lambda(n)=\operatorname{lcm}(p-1,q-1)$ 求逆元也有效。知道 $\varphi(n)$ 会泄露 $p+q=n-\varphi(n)+1$，配合 $pq=n$ 可恢复因子。

### 9.2 ElGamal 的乘法掩码

接收者算 $a^x=(g^k)^x=g^{kx}=y^k$，所以

$$M=b(a^x)^{-1}\bmod p.$$

签名另有 $a=g^k\bmod p$、$b=k^{-1}(M-xa)\bmod{p-1}$，要求 $\gcd(k,p-1)=1$。核验 $y^aa^b\equiv g^M\pmod p$。**数值模 $p$，指数关系模 $p-1$**。

### 9.3 加密、签名、交换密钥的区别

给 Bob 保密：用 Bob 公钥；Alice 签名：用 Alice 私钥；核验 Alice 签名：用 Alice 公钥。基础 RSA 签名模型是 $S=M^d\bmod n$、$S^e\equiv M\pmod n$。DH 不传输完整秘密，也不自动提供身份认证。

课件公式用于学习代数。实际 RSA 加密与签名还包括编码、填充等步骤，例见 [RFC 8017 的 OAEP 与 PSS 规范](https://www.rfc-editor.org/rfc/rfc8017.html)。不把课件的历史密钥长度或简化安全描述当作当前实施规范。

## 10. 容易丢分的条件清单

| 容易写错 | 正确检查 |
| --- | --- |
| “所有 A 是 B”写 AND | 大论域里写 $\forall x(A(x)\to B(x))$ |
| “有 A 是 B”写箭头 | 写 $\exists x(A(x)\land B(x))$ |
| 交换不同类型量词 | 先判断存在变量是否依赖全称变量 |
| 双条件只证一个方向 | 必须证两向 |
| 无限集单射就满射 | 只有有限且等大时能这样推出 |
| 把实际值域当陪域 | 满射要覆盖题目指定的陪域 |
| 0 到 n 写成 n 项 | 实际为 n+1 项 |
| O 就是紧界、Ω 就是最好 | Θ 才表示同阶，输入情形与界是不同维度 |
| 运行 N 次就多项式 | 整数 N 的输入长度约为 log N |
| NP 等于非多项式 | NP 是证书可多项式验证 |
| 新题归约到旧难题就证明新题难 | 证明难要旧难题归约到新题 |
| 同余两边随意约分 | 约掉的因子须与模互素，或正确缩小模数 |
| 同余恰有 d 个整数解 | 是模 m 的 d 个解类，整数解通常无限 |
| 非互素模数直接套 CRT | 先查两两互素条件 |
| Euler 不查互素 | 必须 $\gcd(a,n)=1$ |
| $\varphi(pq)$ 不分 p=q | 不同素数才是 $(p-1)(q-1)$ |
| 域里 0 也有乘法逆元 | 只有非零元素要求逆元 |
| RSA 只用 Euler 证明所有消息 | 不互素情形用逐素数讨论及 CRT |
