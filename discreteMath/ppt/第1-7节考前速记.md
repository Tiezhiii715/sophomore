# 第1–7节考前速记

## 1｜lec01：命题逻辑

- 命题有确定真假；含自由变量的句子通常还不是命题。n个命题的真值表有2ⁿ行。
- **★p→q只有“p真、q假”时为假**；p是q的充分条件，q是p的必要条件；“p only if q”也是p→q。
- 逆否¬q→¬p与原命题等价；逆命题q→p一般不等价。
- p↔q：同真同假；p⊕q：恰有一个为真。∨包含“两者都真”。

## 2｜lec02：等价与量词

- **★p→q ≡ ¬p∨q；¬(p→q) ≡ p∧¬q。**
- 德摩根：¬(p∧q)≡¬p∨¬q；¬(p∨q)≡¬p∧¬q。
- 分配：p∨(q∧r)≡(p∨q)∧(p∨r)；吸收：p∨(p∧q)≡p。
- **★“所有A都是B”：∀x(A(x)→B(x))；“某个A是B”：∃x(A(x)∧B(x))。**先确认论域。
- ∀要对全部成立，∃只需一个例子；恒真式始终真，矛盾式始终假。

作业补充：CNF是“若干∨子句用∧连接”；做法为去→/↔，把¬推到变量前，再分配。例如(p→q)→r ≡ (p∨r)∧(¬q∨r)。

## 3｜lec03：嵌套量词与证明

- **★¬∀x∃yP ≡ ∃x∀y¬P。**翻转每个量词，再否定内部命题。
- ∀x∃y允许y随x变化；∃y∀x要求同一个y。例：实数上∀x∃y(y>x)真，∃y∀x(y>x)假。
- **★恰好一个：∃x[P(x)∧∀y(P(y)→y=x)]。**“至少一个”还不够。
- 推理：p、p→q推出q（MP）；¬q、p→q推出¬p（MT）；p→q、q→r推出p→r。
- 证明只记模板：直接从条件推结论；逆否证¬q→¬p；反证假设p∧¬q；充要条件分两向；否定全称命题给一个反例。存在实例不能当成任意对象来推广。

## 4｜lec04：集合与函数

- **★∅≠{∅}；P(∅)={∅}。**A⊆B指每个A元素都在B中，A⊂B还要求A≠B；本课N包含0。
- A−B=A∩Bᶜ；(A∪B)ᶜ=Aᶜ∩Bᶜ；(A∩B)ᶜ=Aᶜ∪Bᶜ。
- 有限集：|P(A)|=2^|A|；|A×B|=|A||B|；|A∪B|=|A|+|B|−|A∩B|。
- **★单射：f(x)=f(y)⇒x=y；满射：每个陪域元素都有原像；双射：二者兼具。**值域不一定等于陪域，逆函数要求双射。
- (f∘g)(x)=f(g(x))，先g后f。**复合单射⇒g单射；复合满射⇒f满射**，另外两个一般推不出。
- ⌊x⌋向下、⌈x⌉向上：⌊−1.2⌋=−2，⌈−1.2⌉=−1。有限等势集合之间单射⇔满射，无限集不能照搬。

## 5｜lec05：求和与可数性

- **★Σ(k=1到n)k=n(n+1)/2；Σk²=n(n+1)(2n+1)/6；Σk³=[n(n+1)/2]²。**
- Σ(k=0到n)arᵏ=a(1−rⁿ⁺¹)/(1−r)，r≠1；r=1时为(n+1)a。注意从0到n有n+1项。
- **★可数包括有限与可数无限。**N、Z、Q、有限长度字符串可数；R、P(N)、无限0/1序列不可数。
- 可数集的子集可数；有限个可数集的笛卡尔积、可数个可数集的并仍可数。
- 同基数：存在双射；A→B有单射即|A|≤|B|；两边各有单射⇒等势（Schröder–Bernstein）。
- 对角线法：第i位故意与第i项不同，构造名单外的对象。Cantor定理：|A|<|P(A)|。

## 6｜lec06：算法复杂度

- **★充分大时：O是|f|≤C|g|，Ω是|f|≥c|g|，Θ是两者兼有。**O(n²)不等于“恰好二次”。
- 常见增长：1 ≺ log n ≺ n ≺ n log n ≺ n² ≺ n³ ≺ 2ⁿ ≺ n!；log(n!)=Θ(n log n)。
- **★循环数次数：**双重各n次⇒Θ(n²)；内层1到i⇒Σi=Θ(n²)；每次翻倍直到n⇒Θ(log n)。
- Horner嵌套计算n次多项式用Θ(n)次算术操作。插入排序最好Θ(n)、最坏Θ(n²)，平均要说明输入分布。
- **★两个函数均为O(h)，不保证二者同阶或比值O(1)。**反例f=n²、g=1，均为O(n²)，但f/g无界。
- 整数N的二进制输入长度是Θ(log N)，做N次操作相对于位数是指数级。

## 7｜lec07：P/NP与数论入门

- **★P：多项式时间求解的判定问题；NP：yes实例有多项式长度证书，可多项式时间验证。**P⊆NP，NP不是“非多项式”。
- **A≤ₚB：会解B就能解A。**B∈P⇒A∈P；A∈P不能倒推B∈P。
- NP完全：自身在NP，且所有NP问题都可多项式归约到它。**一个NP完全问题有多项式算法⇒P=NP**，不能保证所有问题的算法次数相同。
- a|b表示b=ak；a|b、a|c⇒a|(ub+vc)，u、v为整数。
- **★a=mq+r，0≤r<m。**例：−7除以3，q=−3、r=2。
- a≡b (mod m)⇔m|(a−b)。可以加、减、乘；**不可随便除**：14≡8 (mod6)，却不能推出7≡4 (mod6)。
