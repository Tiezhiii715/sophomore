## 每篇怎么学

先读引入场景，自己猜解决办法；再看反例为什么推翻原办法。看 SQL 前先说“一行代表什么”，看完用文末自测检查能否解释原因。文中显式标注的“补充”用于讲清省略细节，不能当老师已系统讲授的额外章节。SQL 默认沿用大总结的四表模型，扩展表、产品方言和示例前提会单独说明。
