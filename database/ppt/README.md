## 阅读入口

- [数据库原理复习总结](数据库原理复习总结.md)：查知识点、SQL 模板、易错点、18 道自测与答案。
- [分节通俗讲解](分节讲解/README.md)：每份课件一篇，详细讲“什么情况促使我们引入这个知识、怎么解决、为什么这样写”。
- [最新第 7 节](分节讲解/07-搜索、事务、自动编号与数据导入.md)：搜索、事务与 ACID、MVCC、WAL、自动编号、文件导入。

前 6 节分别覆盖数据库与建模、建表约束、单表查询、去重聚合和连接、外连接与子查询、排序和窗口函数。第 7 节已优先处理，前 6 节独立讲解也已补齐。

## 以后怎样更新

每次新增或替换课件，默认同时：

1. 先阅读最新课件，补充大总结并校正冲突。
2. 为对应课件写或更新一份详细讲解，按“情况 → 原方法的问题 → 解决方法 → 知识点 → 例子/反例/自测”组织。
3. 补历史遗漏，更新目录、来源指纹、覆盖页数与记录，再同步 GitHub。

固定大总结链接不变；同一节原位更新。原课件保留本地，笔记区分课件内容、解释性补充和产品版本差异。完整维护约定见大总结末尾。
