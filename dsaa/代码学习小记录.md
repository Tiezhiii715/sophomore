# 代码学习小记录

## 001｜逻辑表达式求值

记录日期：2026-11-13  
语言：Java  
关键词：栈、表达式求值、BufferedReader、位运算

### 简略题意

输入 T 个合法逻辑表达式，包含 0、1、括号以及 !、&、|、^、->，输出每个表达式的值。

每个运算都有完整括号，例如 `(!1)`、`(1&0)`、`(0->1)`。所有表达式的总长度不超过 10^6。

示例：`(!(!(1^1)))` 的结果是 0。

### 解题思路

- 我想到了遇到右括号就算。
- 我有点不确定的点是怎么把东西存数组里。（最一开始，然后就问ai了）
- 完全没想到模拟栈。


从左到右扫描，用字符数组模拟栈：

1. 遇到 `(`，直接忽略。
2. 遇到 `>`，直接忽略；用 `-` 代表整个 `->`。（这点没想到）
3. 遇到数字或运算符，入栈。
4. 遇到 `)`，弹出右操作数 b 和运算符。若为 `!`，直接取反；否则再弹出左操作数 a，完成运算。将结果重新入栈。
5. 扫描结束，栈中剩下的字符就是答案。

### Java 参考代码

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(
                new InputStreamReader(System.in));
        int t = Integer.parseInt(br.readLine().trim());
        StringBuilder output = new StringBuilder();

        while (t-- > 0) {
            String s = br.readLine().trim();
            char[] stack = new char[s.length()];
            int top = 0; // 指向下一个可写入的位置

            for (int i = 0; i < s.length(); i++) {
                char c = s.charAt(i);
                if (c == '(' || c == '>') continue;

                if (c != ')') {
                    stack[top++] = c;
                    continue;
                }

                int b = stack[--top] - '0';
                char op = stack[--top];
                int result;

                if (op == '!') {
                    result = b ^ 1;
                } else {
                    int a = stack[--top] - '0';
                    switch (op) {
                        case '&': result = a & b; break;
                        case '|': result = a | b; break;
                        case '^': result = a ^ b; break;
                        default: result = (a ^ 1) | b; break; // ->
                    }
                }
                stack[top++] = (char) ('0' + result);
            }
            output.append(stack[0]).append('\n');
        }
        System.out.print(output);
    }
}
```

### 我这次问过的问题

`int a = stack[--top] - '0'`为啥要减0：
 
这里减的是字符 '0'，不是数字 0，目的是把字符转换成整数。

因为 stack 是 char[]，存进去的是字符 '0' 或 '1'。字符参与运算时，使用的是它的编码值：

- '0' 的编码是 48
- '1' 的编码是 49

所以减去 '0' 后：

```java
'0' - '0'  // 48 - 48 = 0
'1' - '0'  // 49 - 48 = 1
```

### 能从这道题学到什么

- 模拟栈（我一开始想的是把东西先存再操作，其实可以同时）
- 怎么把一串字符串拆成字符数组
- 那些逻辑运算符的电脑表达。（蕴含，还有取反）


1. **栈适合处理嵌套结构。** 内层表达式先结束、先计算，符合栈“后进先出”的特点。遇到括号匹配、嵌套计算，可以先考虑栈。
2. **善用题目保证。** 所有运算都有括号，因此不需要处理运算符优先级，也不需要复杂的语法分析。
3. **数组模拟栈。** `stack[top++] = c` 表示先写入再移动指针；`stack[--top]` 表示先移动指针再取出栈顶。栈中元素个数始终为 `top`。
4. **注意操作数顺序。** 先弹出来的是右操作数 b，再弹出的是左操作数 a。对于 `a -> b`，左右不能交换。
5. **理解蕴含。** `a -> b` 等价于 `非 a 或 b`，只有 a=1、b=0 时结果为 0。四种情况依次为：0->0=1、0->1=1、1->0=0、1->1=1。原题真值表排版有误，以此为准。
6. **0/1 可以用位运算表示逻辑运算。** `a & b`、`a | b`、`a ^ b` 分别对应与、或、异或。对于只可能是 0/1 的值，`a ^ 1` 可以取反；不能用 `~a`，因为它会翻转整数的所有二进制位。
7. **字符和数字需要转换。** `c - '0'` 把字符 '0'/'1' 转为整数；`(char) ('0' + result)` 把结果转回字符。
8. **数据规模决定写法。** 长度可达 10^6，递归求值可能因嵌套过深而栈溢出。迭代加显式栈更稳妥；每个字符最多入栈、出栈一次，时间 O(n)、空间 O(n)。
